 0. 한눈에 보기
================================================================================

CEditorMenuBar 는 CWidgetContainer 를 상속하며, UIManager 가 ZOrder 100 으로
생성합니다. 화면 최상단 1280 x 40 영역을 차지합니다.

  EditorWorld.cpp:39   auto MenuBarWeak = UIMgr->CreateWidgetContainer<CEditorMenuBar>("EditorMenuBar", 100);
  MainWorld.cpp:57     (동일)

엔진의 위젯 시스템(CWidgetContainer + CButton + CTextBlock) 위에 직접 만든
retained 방식 드롭다운입니다. 즉시모드(ImGui) 방식이 아닙니다.

위젯 트리는 평평(flat)합니다.

  CEditorMenuBar (0,0, 1280x40)
  |
  +- "MenuBarBg"        CButton           ZOrder 0   <- 단순 배경(모든 상태 동일 색)
  +- "EmptyActorBtn"    CButton           ZOrder 1  + "EmptyActorBtn_Lbl" CTextBlock ZOrder 2
  +- "AddComponentBtn"  CButton           ZOrder 1  + Lbl
  +- "SceneBtn"         CButton           ZOrder 1  + Lbl
  +- "PrefabBtn"        CButton           ZOrder 1  + Lbl
  +- "MaterialBtn"      CButton           ZOrder 1  + Lbl
  +- "AnimEditorBtn"    CButton           ZOrder 1  + Lbl
  |
  +- "Submenu"          CWidgetContainer  ZOrder 2   (기본 Disable, 11행)
  +- "SceneSubmenu"     CWidgetContainer  ZOrder 2   (기본 Disable,  2행)
  +- "PrefabSubmenu"    CWidgetContainer  ZOrder 2   (기본 Disable,  2행)
  +- "MaterialSubmenu"  CWidgetContainer  ZOrder 2   (기본 Disable,  1행)

핵심 포인트 : 라벨 텍스트는 버튼의 "자식"이 아니라 "형제" 위젯입니다.
같은 좌표/같은 크기의 CTextBlock 을 ZOrder 한 단계 높게 겹쳐 그립니다.


 [ 메뉴 구성 표 ]

  X 좌표 | 버튼            | 트리거   | 동작
  -------+-----------------+----------+-------------------------------
    10   | Empty Actor     | Clicked  | 즉시 액터 생성
   140   | Add Component   | Hovered  | 11행 서브메뉴
   300   | World           | Hovered  | Save / Load World
   410   | Prefab          | Hovered  | Save / Load Prefab
   520   | Material        | Hovered  | New Material Editor
   630   | Anim Editor     | Clicked  | 패널 토글

  => 드롭다운 부모는 전부 "호버"로 열리고,
     클릭 액션 버튼(Empty Actor / Anim Editor)은 서브메뉴가 없습니다.

 [ 3-1. 상단 메뉴 버튼 ]  EditorMenuBar.cpp:46~75

    static std::weak_ptr<CButton> MakeMenuButton(CWidgetContainer* Parent,
        const std::string& Name, float X, float W, const wchar_t* Label)
    {
        auto Btn = Parent->CreateWidget<CButton>(Name, 1);      // ZOrder 1
        auto B = Btn.lock();
        if (B)
        {
            B->SetPos(X, BTN_Y);
            B->SetSize(W, BTN_H);
            B->SetTint(EWidgetState::Normal,  0.65f, 0.65f, 0.70f, 1.f);
            B->SetTint(EWidgetState::Hovered, 0.85f, 0.85f, 1.00f, 1.f);
            B->SetTint(EWidgetState::Clicked, 1.00f, 1.00f, 1.00f, 1.f);
            B->SetTint(EWidgetState::Release, 0.85f, 0.85f, 1.00f, 1.f);
            B->SetTint(EWidgetState::Disable, 0.35f, 0.35f, 0.35f, 0.5f);
        }

        auto Text = Parent->CreateWidget<CTextBlock>(Name + "_Lbl", 2);  // ZOrder 2
        if (auto T = Text.lock())
        {
            T->SetPos(X, BTN_Y);          // <- 버튼과 완전히 같은 좌표/크기
            T->SetSize(W, BTN_H);
            T->SetText(Label);
            T->SetFontSize(14.f);
            T->SetTextColor(FVector4::White);
            T->SetAlignH(ETextAlignH::Center);
            T->SetAlignV(ETextAlignV::Middle);
        }

        return Btn;   // 버튼만 반환 - 텍스트는 이후 건드릴 일이 없으므로 버림
    }

 설명
   - 엔진의 CButton 에 텍스트 기능이 없어서, 같은 사각형에 CTextBlock 을
     ZOrder 한 단계 높게 덮어씌우는 방식으로 라벨을 만듭니다.
   - 부모-자식이 아니라 "형제" 라는 점이 중요합니다.
     버튼을 옮기면 라벨은 따라오지 않습니다.
   - 5개 상태 틴트는 EWidgetState 를 그대로 따라갑니다.
   - Release(뗀 직후)를 Hovered 와 같은 색으로 준 이유는 클릭을 놓았을 때
     색이 튀지 않게 하려는 것이며, 뒤에 나오는 IsActive() 와 짝을 이룹니다.


 [ 3-2. 서브메뉴 버튼 ]  EditorMenuBar.cpp:77~106

    static std::weak_ptr<CButton> MakeSubmenuButton(CWidgetContainer* Parent,
        const std::string& Name, int Row, const wchar_t* Label)
    {
        auto Btn = Parent->CreateWidget<CButton>(Name, 1);
        auto B = Btn.lock();
        if (B)
        {
            B->SetPos(0.f, Row * SUBMENU_BTN_H);      // <- 세로로 쌓기
            B->SetSize(SUBMENU_W, SUBMENU_BTN_H);
            B->SetTint(EWidgetState::Normal,  0.55f, 0.55f, 0.60f, 0.95f);
            B->SetTint(EWidgetState::Hovered, 0.40f, 0.60f, 1.00f, 1.f);  // 파란 하이라이트
            B->SetTint(EWidgetState::Clicked, 0.60f, 0.80f, 1.00f, 1.f);
            B->SetTint(EWidgetState::Release, 0.40f, 0.60f, 1.00f, 1.f);
            B->SetTint(EWidgetState::Disable, 0.30f, 0.30f, 0.30f, 0.5f);
        }

        auto Text = Parent->CreateWidget<CTextBlock>(Name + "_Lbl", 2);
        if (auto T = Text.lock())
        {
            T->SetPos(0.f, Row * SUBMENU_BTN_H);
            T->SetSize(SUBMENU_W, SUBMENU_BTN_H);
            T->SetText(Label);
            T->SetFontSize(14.f);
            T->SetTextColor(FVector4::White);
            T->SetAlignH(ETextAlignH::Center);
            T->SetAlignV(ETextAlignV::Middle);
        }

        return Btn;
    }

 설명
   - X 대신 "행 인덱스(Row)" 를 받아 Y = Row * 32 로 세로 배치합니다.
   - 좌표가 (0, Row*32) 인 이유는 "서브메뉴 컨테이너 기준 로컬 좌표" 이기
     때문입니다. 컨테이너 자체를 (140, 40) 에 놓으면 자식들이 통째로 따라갑니다.

 [ 5-a. 활성 판정 헬퍼 ]  EditorMenuBar.cpp:249~260

    // Hovered, Clicked, Release 세 상태 모두 "활성" 으로 판단
    static bool IsActive(const std::weak_ptr<CButton>& W)
    {
        auto B = W.lock();
        if (!B) return false;
        auto S = B->GetWidgetState();
        return S == EWidgetState::Hovered
            || S == EWidgetState::Clicked
            || S == EWidgetState::Release;
    }

    static constexpr float CLOSE_DELAY = 0.08f; // 허용 갭 시간 (초)

                    FVector2 MP = Input->GetMousePos();

                    // 메뉴바 자체 영역 (Y < BAR_H)
                    bool InMenuBar = (MP.y >= 0.f && MP.y < BAR_H);

                    // 열린 서브메뉴 영역
                    bool InAnySub = false;
                    auto CheckSub = [&](const std::weak_ptr<CWidgetContainer>& SubW, float LocalX)
                    {
                        auto Sub = SubW.lock();
                        if (!Sub || !Sub->IsEnable()) return;      // 닫힌 메뉴는 무시
                        FVector3 SubSize = Sub->GetSize();
                        if (MP.x >= LocalX && MP.x < LocalX + SubSize.x &&
                            MP.y >= BAR_H  && MP.y < BAR_H  + SubSize.y)
                            InAnySub = true;
                    };
                    CheckSub(mSubmenu,         140.f);
                    CheckSub(mSceneSubmenu,    300.f);
                    CheckSub(mPrefabSubmenu,   410.f);
                    CheckSub(mMaterialSubmenu, 520.f);

                    if (!InMenuBar && !InAnySub)
                    {
                        // 모든 서브메뉴 즉시 닫기
                        auto ForceClose = [](bool& Open, float& Timer,
                                             const std::weak_ptr<CWidgetContainer>& SubW)
                        {
                            Open = false; Timer = 0.f;
                            if (auto S = SubW.lock()) S->SetEnable(false);
                        };
                        ForceClose(mSubmenuOpen,         mSubmenuCloseTimer,  mSubmenu);
                        ForceClose(mSceneSubmenuOpen,    mSceneCloseTimer,    mSceneSubmenu);
                        ForceClose(mPrefabSubmenuOpen,   mPrefabCloseTimer,   mPrefabSubmenu);
                        ForceClose(mMaterialSubmenuOpen, mMaterialCloseTimer, mMaterialSubmenu);
                    }
                }
            }
        }
    }

 설명
   - 히트 테스트는 두 가지입니다.
       InMenuBar : MP.y < 40 이면 메뉴바 위
       InAnySub  : 열려 있는 각 서브메뉴의
                   [X, X+Width] x [40, 40+Height] 사각형과 비교
   - 둘 다 아니면 ForceClose 로 네 메뉴를 타이머 무시하고 전부 닫습니다.
   - ForceClose 가 bool&, float& "참조" 를 받는 덕에 네 메뉴를 한 줄씩으로 닫습니다.
   - 가장 바깥 if 로 하나도 안 열렸을 때는 입력 조회 자체를 건너뜁니다.

 (1) SetEnable() 하나로 열림/닫힘
