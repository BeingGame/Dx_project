윈도우 창 생성
렌더링할수 있는 환경을 준비한다.

윈도우 창 클래스를 생성해서 아이콘, 메뉴, 창 이름등을 설정해서
새로운 윈도우창을 만들어냈다. CreateWindowW

윈도우창의 해상도
창의 전체영역이 우리가 설정한 해상도의 크기랑 동일했다.
클라이언트 영역은 항상 해상도보다 작다.
따라서 새로 작업을 해서 윈도우 창의 해상도를 우리가 설정한 해상도로 변경했다.
AdjustWindowRect, SetWindowPos를 사용해서 Rect의 right - left와 bottom - top을 이용해 해상도를 구한다.

라이브러리
기능을 묶어놓은 코드뭉치

정적, 동적 라이브러리

정적 라이브러리
코드가 복사되서 생성된다.
똑같은 라이브러리를 사용하더라도 각자 메모리에 중복된 코드를 적재하게된다.

동적 라이브러리
컴파일 시점에 링크만 걸어두고, 실행할때 라이브러를 메모리에 불러온다.
파일 크기가 복사되는게 아니라 정적 라이브러리보다 작다. dll만 변경하면 재컴파일 할필요 없다.
중복 프로그램에서 메모리를 공유해서 사용할수 있다.
정적 라이브러리에 비해서 상대적으로 느리다.

클라이언트는 데스크톱 어플리케이션, 엔진은 라이브러리로 만들어 연결한다.

엔진 클래스를 만들어서 윈도우 창을 생성하고,
하나밖에 없기때문에 싱글톤으로 생성하며, 프로그램의 실행을 총괄하기 때문에 매니저 종류를 엔진에서 생성한다.

디바이스 클래스
렌더링과 관련된 컴객체와 스왑체인, 그리고 렌더타겟을 가지고 있는 클래스
해당 클래스가 모든 GPU관련 명령을 내릴수 있기 때문에 중요도가 상당히 높다.

스왑체인
백버퍼 개념, 이중버퍼링을 이용해서 정면과 후면 버퍼를 교체한다.
버퍼를 2개가 아니라 여러개를 더 넣어서 순차적으로 출력하도록 할수도 있다.

스왑체인을 이용해 백버퍼를 생성한다음, 렌더 타겟 뷰를 만들고
또한 뎁스버퍼를 생성해서 뎁스 스텐슬 뷰를 만들어낸다.

벡터랑 행렬 생성

렌더링 파이프라인 단계
IA -> 버텍스 셰이더 -> 레스터라이저 -> 픽셀 셰이더 -> 출력 병합

IA
CPU에서 정점을 계산한다음 버텍스 셰이더에서 사용할수 있도록
GPU에 데이터를 넘겨준다.
받아온 정점을 삼각형(기본도형)으로 구성한다.
기본도형(프리미티브)는 필요시 변경이 가능하다.(점,선,삼각형)

버텍스 셰이더
받아온 정점데이터를 공간 좌표계(clip space)로 변환한다.

월드 변환
월드행렬이용 해서 월드 좌표로 변경해준다.
오브젝트의 로컬 좌표를 월드좌표로 변경하기 위해 행렬을 곱해준다.
월드 원점으로 기준으로 오브젝트의 배치를 정한다.

뷰 변환
카메라를 기준으로 물체를 렌더링 하기전에 원점을 기준으로 변경한다.
모든 오브젝트의 위치를 카메라가 원점으로 이동한 만큼 이동시켜 계산을 쉽게 한다.
카메라의 절두체에 들어오지않은 오브젝트들은 컬링한다.

투영 변환
원근감을 적용하기 위해서 오브젝트의 위치를 공간 좌표계로 이동시킨다.
직교, 원근 투영
변환할때 4D를 이용해서 한다.

==GPU가 알아서 해주는 단계==
w값 카메라와의 거리
x,y,z, w값으로 나누어 NDC공간(x,y : -1 ~ 1 , z : 0~1) 사이의 값으로 변경한다.

레스터라이저
버텍스 셰이더에서 변환된 정점 정보를 화면에 픽셀로 입력해주는 단계
NDC-> 2D로 표현하기 위해 2D스크린 좌표로 옮겨준다.
x,y값을 스크린에 픽셀데이터로 저장하고, z값을 깊이로 저장한다.
back face culling :후면을 컬링한다.
==GPU가 알아서 해주는 단계==

픽셀 셰이더
픽셀 하나하나의 색상을 계산한다.
GPU가 해상도의 픽셀만큼 셰이더를 호출해서 계산한다.
최종적으로 색상값과 깊이값을 저장한다.

출력 병합
렌더링 파이프라인의 마지막 단계
최종적으로 나온 알파값, 깊이갚들을 픽셀끼리 경쟁시켜 화면에 그려질 픽셀을 정한다.

메쉬는 IA에 정점데이터 넣어서 필요한 도형을 표현하기위해 만들어진 클래스
셰이더 버텍스랑, 픽셀 셰이더를 직접 생성해서 필요시에 정점 데이터 연산과, 픽셀 색상 연산을 직접 해주기위해 만들어준다.

셰이더는 컴파일을 위해 경로를 가지고있는 PathManager를 생성해준다.

PathManager -> 출력 디렉토리 경로를 이용해서 셰이더 코드가 있는 위치를 지정해서 경로를 만들어준다.
